# Gestor de tareas en Python

Mi primer proyecto desarrollado en Python. Este programa permite gestionar tareas desde la consola mediante un menú interactivo. 

## 🚀 Funcionalidades

- 📋 Ver tareas.
- ➕ Agregar tareas.
- ✅ Marcar tareas como completadas.
- 🗑️ Eliminar tareas.
- 💾 Guardar tareas en un archivo `.txt`.

## 🛠️ Tecnologías utilizadas

- Python
- Git
- GitHub

## ▶️ Cómo ejecutar el proyecto

1. Clona este repositorio:

```bash
git clone https://github.com/sergioquinones017/Gestor_de_tareas_python.git
```

2. Entra a la carpeta del proyecto:

```bash
cd Gestor_de_tareas_python
```

3. Ejecuta el programa:

```bash
python Gestor_Tareas.py
```
