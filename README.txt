# Gestor de Tareas en Python

Mi primer proyecto realizado en Python.

## Descripción

Este programa permite administrar una lista de tareas desde la consola.

## Funciones

- Ver tareas.
- Agregar nuevas tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Guardar las tareas en un archivo antes de salir.

## Tecnologías utilizadas

- Python 3

## Lo que aprendí

Durante este proyecto aprendí a utilizar:

- Variables.
- Listas.
- Ciclos `while` y `for`.
- Condicionales `if`, `elif` y `else`.
- `enumerate()`.
- `append()`.
- `pop()`.
- Lectura y escritura de archivos con `open()`.
- Manejo de la entrada del usuario con `input()`.
